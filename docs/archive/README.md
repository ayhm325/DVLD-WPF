## 1. Overview and Archival Purpose

This directory (`docs/archive/`) permanently preserves historical planning deliverables, early architecture drafts, and original security source documents from earlier phases of the DVLD modernization project.

### Core Governance Rules for Archived Assets:
1. **Preserved for Historical Traceability:** These files provide an audit trail of architectural evolution, initial discovery thinking, and original risk assessments.
2. **Zero Active Implementation Authority:** Archived documents do **NOT** represent active execution plans, current architecture standards, approved decisions, or implementation authorization.
3. **No Overriding Active Documentation:** Archived files must **never** be cited to override, weaken, or challenge the active root governance suite or civic domain specifications.
4. **Historical Status of Proposals:** Proposals, candidate parameters, or unapproved workflows found within archived documents remain strictly unapproved unless formally ratified in [`ENGINEERING-DECISIONS.md`](../../ENGINEERING-DECISIONS.md).
